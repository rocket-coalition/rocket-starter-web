# Contributing to Rocket Starter Web

Thank you for helping build Rocket Starter Web!

## How We Work

- All work happens in feature branches (e.g., `feature/your-feature`)
- Open a Pull Request to `main` when ready
- Link PRs to issues when possible
- Keep commits focused and clear
- Use the provided issue and PR templates

## Using AI Agents

We use GitHub Copilot agents to streamline development:

- **For new issues**: Invoke `@copilot issue-planner.md` to generate implementation plans
- **For code review**: Use `@copilot code-reviewer.md` to get automated feedback
- **For task planning**: Use `@copilot task-delegator.md` to identify delegatable work

See [`.github/agents/QUICK-START.md`](.github/agents/QUICK-START.md) for details.

**Questions?** Open an issue or start a discussion!
