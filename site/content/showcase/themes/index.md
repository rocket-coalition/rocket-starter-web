## Overview

This page is the definitive, designer-facing gallery for Rocket themes. Every swatch, gradient, and component below is driven entirely by CSS custom properties; edit the LCH inputs inside `input.css`, reload, and this page becomes your QA board.

## Typography Stack

<article class="prose max-w-none">
  <h1>Display Heading · `--heading`</h1>
  <p class="lead">Lead copy renders using <code>--fg-muted</code>, while body text uses <code>--fg</code>. Any change to those tokens updates every article instantly.</p>
  <h2>Section Heading · `--text-3xl`</h2>
  <p>Body paragraphs adapt to <code>--leading-relaxed</code> and <code>--font-sans</code>.</p>
  <h3>Subheading</h3>
  <p><a href="#">Links</a> automatically inherit the primary ramp via DaisyUI tokens.</p>
</article>

## Reference Checklist

1. Adjust `--L/C/H-primary` and `--L/C/H-secondary`.
2. Update surfaces/ink (`--bg`, `--fg`, `--heading`).
3. Re-map Daisy base tokens (ensures components follow suit).
4. Verify ramps, gradients, status blocks, and typography using this page.
5. Promote stable values to `rocket-ui.css` for reuse across apps.
